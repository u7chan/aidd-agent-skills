# PR作成

作業ブランチを push して PR を作成する。

## ルール

- PR 作成前に、意図した差分だけが含まれていることを確認する。
- 作業ブランチを push して PR を作成する。
- PR タイトルは変更内容を簡潔に表す。
- Issue を閉じる場合は `Close #<no>`、関連付けのみなら `Refs #<no>` を使用する。
- `Changes` は少量なら箇条書き、変更が多い場合は領域や目的ごとにグループ化して構造化する。
- PR 本文は必ず本テンプレートで作成する。他のテンプレートは使用しない。

```markdown
## Issues

<!-- Close #<no> or Refs #<no> -->

## Why

<!-- 変更が必要な背景を書く -->

## Summary

<!-- この PR の概要を書く -->

## Changes

<!--
少量なら箇条書きで書く。

- 変更点 1
- 変更点 2

変更が多い場合は、領域や目的ごとにグループ化する。

### <group>

- 変更点 1
- 変更点 2
-->

## Verification

<!--
- `command` - passed
-->
```
