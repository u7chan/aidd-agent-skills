# 進捗管理表テンプレート

`/tmp/aidd-agent/task-{identifier}-{timestamp}.md` として作成する進捗管理表のテンプレート。
既存プロジェクトに別の規約がある場合は、既存規約を優先する。
リポジトリに残す必要がある場合だけ、ユーザーに確認して保存先を変更する。

````markdown

4. `git status` と `git diff` で実際の差分を確認する。
````
