# aidd-agent-skills

AI駆動開発における開発工程を、自律型AIエージェントへ委譲し支援を受けるためのスキル群。

スキルの数が増えるほど利用者ごとのAI活用スキルに依存しやすくなり、運用や学習コストも増加する。
そのため、本プロジェクトでは開発者が迷わず利用できることを重視し、提供するスキルを必要最小限に絞っている。

## 提供スキル

| スキル | 工程 | 目的 |
|--------|------|------|
| dev-plan | 計画 | 計画の壁打ち、設計書・進捗管理表の作成 |
| dev-start | 開発 | 計画に基づく開発・品質確認・テスト、PRの作成 |
| dev-resume | 再開 | 進捗管理表に基づく開発の再開、PRのFB対応 |
| dev-review | レビュー | コードレビュー・品質確認 |
