# aidd-agent-skills

AI駆動開発における計画・実装・再開・レビューの各工程を、自律型AIエージェントへ委譲し支援を受けるためのスキル群。

スキルの数が増えるほど利用者ごとのAI活用スキルに依存しやすくなり、運用や学習コストも増加する。
そのため、本プロジェクトでは開発者が迷わず利用できることを重視し、提供するスキルを必要最小限に絞っている。
`dev-plan` で計画や設計、進捗管理表を作成し、`dev-start` で実装を進め、`dev-resume` で進捗管理表をもとに作業を再開する流れを想定している。

## 提供スキル

| スキル | 工程 | 目的 |
|--------|------|------|
| dev-plan | 計画 | 調査、要求整理、設計、検証計画、進捗管理表の作成 |
| dev-start | 開発 | 計画に基づく開発・品質確認・テスト、進捗管理表の更新、PRの作成 |
| dev-resume | 再開 | 進捗管理表に基づく開発の再開、PRのFB対応 |
| dev-review | レビュー | Issue・PRを対象とした要件・設計・実装の妥当性レビュー |
